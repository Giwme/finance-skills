# Finance Skills

This repository packages finance-related OpenClaw / AgentSkill folders.

## Included skills

- `competitive-analysis` — Competitive landscape analysis framework for market structure, peer positioning, moat assessment, and strategic recommendations.
- `wind-mcp-skill` — Wind financial data access skill covering equities, funds, indices, bonds, announcements, news, macro, and industry indicators.
- `thesis-tracker` — Maintains investment theses for positions/watchlists, tracks thesis pillars, data points, catalysts, risks, scorecards, and conviction changes.
- `earnings-analysis` — Professional quarterly earnings update framework for beat/miss analysis, source-backed metrics, estimate revisions, thesis impact, and DOCX report creation.
- `process-letter` — Sell-side M&A process letters and bid instructions, including IOI requirements, final bid procedures, and management meeting logistics.
