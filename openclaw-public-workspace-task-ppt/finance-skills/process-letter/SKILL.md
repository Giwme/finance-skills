# Process Letter

Draft clear, professional sell-side M&A process letters and bid instructions. Cover initial indications of interest (IOI), final bid procedures, and management meeting logistics.

## Workflow

### Step 1: Determine Letter Type

Identify the requested document type before drafting:

- **Initial process letter**: Sent with teaser/CIM to outline process and IOI requirements.
- **IOI instructions**: Specific requirements for first-round indications.
- **Second round / final bid letter**: Instructions for submitting binding offers.
- **Management meeting invitation**: Logistics for in-person or virtual management presentations.

If the user has not specified enough deal details, proceed with sensible placeholders rather than blocking, unless a legal or commercial point is impossible to infer safely.

### Step 2: Initial Process Letter / IOI Instructions

Include the following components:

**Header:**

- Date
- Deal code name
- “Confidential”
- Address to the prospective buyer or buyer representative

**Sections:**

1. **Introduction**
   - Briefly describe the opportunity.
   - State the seller’s objectives and desire to run an organized process.
2. **Process Overview**
   - Timeline and key dates.
   - Expected number of process rounds.
   - Data room / CIM / management access sequencing, if applicable.
3. **IOI Requirements**
   - Proposed valuation range, typically enterprise value.
   - Consideration form: cash, stock, earnout, rollover, or combination.
   - Financing sources and financing certainty.
   - Key due diligence requirements.
   - Indicative timeline to signing and closing.
   - Conditions or contingencies.
   - Brief buyer description and strategic rationale.
4. **Submission Details**
   - Submission recipient(s).
   - Deadline, time zone, and format.
   - Required file type, usually PDF on buyer letterhead.
5. **Confidentiality Reminder**
   - Reference the executed NDA.
   - Remind buyers that data room materials and process communications are confidential.
6. **Contact Information**
   - Banker / adviser contacts for process questions.

### Step 3: Final Bid / Second Round Letter

For final bid or second-round instructions, add these requirements:

1. **Markup of Purchase Agreement**
   - Provide draft SPA/APA instructions.
   - Request a blackline / markup and issues list.
2. **Detailed Financing Commitments**
   - Require committed financing letters where applicable.
   - Ask for equity commitment letters, debt commitment papers, and any conditions.
3. **Remaining Diligence Items**
   - Specify confirmatory diligence expected after bid submission.
   - Ask bidders to confirm whether diligence is substantially complete.
4. **Exclusivity Terms**
   - Request proposed exclusivity duration and conditions, if relevant.
5. **Regulatory Analysis**
   - Require antitrust / merger control filing assessment.
   - Ask for timing, approvals, remedies risk, and buyer mitigation plan.
6. **Key Personnel Terms**
   - Address employment agreements, retention, compensation, rollover equity, and management treatment.
7. **Binding vs. Non-Binding**
   - Clarify which parts of the proposal are intended to be binding at this stage.
   - Coordinate legal language carefully.
8. **Evaluation Criteria**
   - State that bids may be evaluated on value, certainty, speed, contractual terms, financing, regulatory risk, diligence status, management treatment, and overall deliverability.

### Step 4: Management Meeting Invitation

For management meeting invitations, include:

1. **Logistics**
   - Date, time, location / video link, duration, and arrival instructions.
2. **Attendees**
   - Company presenters.
   - Buyer attendees and role expectations.
3. **Agenda**
   - Company overview.
   - Market and strategy.
   - Financial performance.
   - Operations / commercial deep dive.
   - Q&A.
4. **Ground Rules**
   - No recording.
   - Maintain confidentiality under NDA.
   - Questions should be directed through advisers unless otherwise permitted.
5. **Materials**
   - Identify presentation materials to be distributed or made available in the data room.
6. **Follow-Up**
   - Explain process for additional diligence questions and follow-up requests.

### Step 5: Output Requirements

When asked to produce a process letter, deliver:

- A polished Chinese or English draft, matching the user’s requested language.
- Professional letter formatting suitable for conversion to Word.
- Firm letterhead placeholder if no letterhead is provided.
- Clear placeholders for missing deal-specific items.
- A client-review version with comments or bracketed alternatives where commercial/legal choices are needed.

If the user requests files, create a `.docx` when tooling is available. If track changes are requested but native redline generation is unavailable, provide a clean version plus a marked-up review version with bracketed comments.

## Important Notes

- Process letters set the tone for the entire deal; be clear, organized, and professional.
- Deadlines should be firm but reasonable: typically 2–3 weeks for IOIs and 3–4 weeks for final bids.
- Always include evaluation criteria so bidders understand how proposals will be judged.
- Coordinate with legal counsel on representations, binding language, exclusivity, regulatory commitments, and purchase agreement instructions.
- Client should review and approve any letter before external distribution.
- Keep a log of who received each letter and when.
- Analysis and drafts are for reference only and do not constitute legal, tax, investment, or financial advice.
