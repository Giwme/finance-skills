# 图表与配色规范

## 品牌配色（华为模板规范）

**严格遵循上传的PPT模板风格：白底、黑色/深灰正文、华为红色线条与强调。**

```
背景色：           #FFFFFF  ← 幻灯片背景（纯白）
主要文字：         #1D1D1A  ← 标题、正文主体
华为红（主强调）：  #C00000  ← 线条、分隔符、关键词高亮、图表强调色
华为红（深）：      #C7000A  ← 可替代使用，与C00000同系
浅灰色框：         #F4F4F4  ← 内容卡片背景、区域底色
中灰色：           #919191  ← 次要文字、图注、说明文字
深灰色：           #666666  ← 副标题、辅助文字
图表辅助色1：      #C4C4C4  ← 次要数据系列、对比色（浅）
图表辅助色2：      #F4A100  ← 警示/特殊标注（橙色，模板中有使用）
禁止使用：         深色背景、蓝色系主色、金色系
```

**颜色使用优先级：**
1. 最重要的数字/观点 → 华为红 `#C00000` 加粗
2. 普通正文 → `#1D1D1A`
3. 次要说明 → `#919191`
4. 区域底色 → `#F4F4F4` 浅灰
5. 图表第一系列 → `#C00000`，第二系列 → `#C4C4C4`，第三系列 → `#1D1D1A`

## 图表类型规范

### 1. 上下文长度对比折线图

**用途：** 展示主流模型上下文窗口演进趋势

**数据结构：**
```json
{
  "title": "主流大模型上下文窗口演进（tokens）",
  "xAxis": "时间（季度）",
  "yAxis": "上下文长度（K tokens）",
  "series": [
    {"name": "Claude系列", "color": "#C9A84C"},
    {"name": "GPT系列", "color": "#1B2A4A"},
    {"name": "Gemini系列", "color": "#2D6A4F"},
    {"name": "国内模型", "color": "#6B7280"}
  ],
  "注意": "每次执行时从实时搜索填充真实数据"
}
```

**PPT呈现建议：**
- 在折线终点标注最新数字（如"1M tokens"）
- 添加右侧注释列：对应银行业务含义（如"可处理完整信贷合同"）
- Y轴用对数刻度，更清楚展示倍数增长

## PPT幻灯片布局模板

### 封面幻灯片
```
背景：深色渐变 #1B2A4A → #0D1B2A
中央：白色主标题（44pt，Calibri Bold）
下方：金色副标题（20pt）
左下角：报告日期（小字）
右下角：机构logo位
装饰：右侧金色几何线条
```

### 内容幻灯片（含图表）
```
顶部：标题栏 #1B2A4A，白色标题文字
左侧60%：图表/可视化
右侧40%：
  - 核心洞察（金色加粗，18pt）
  - 3条要点（正常文字，14pt）
  - 底部来源注释（灰色，10pt）
```

### 对比幻灯片
```
顶部：标题栏
中部：双列布局（AS-IS / TO-BE）
底部：蓝色横条：转型价值总结（如"效率提升80%，成本降低60%"）
```

### 建议幻灯片
```
背景：浅色 #F5F7FA
四个卡片布局（2×2网格）
每个卡片：
  - 顶部色条（不同颜色区分四维度）
  - 图标
  - 标题（18pt Bold）
  - 3条要点（14pt）
```

## 数字呈现规范

- **大数字强调**：ROI、节省比例用60-72pt金色字体
- **对比数字**：AS-IS用普通黑色，TO-BE用蓝色加粗
- **百分比变化**：正向绿色 ↑，负向红色 ↓
- **时间单位**：统一用"分钟/小时/天"，不用小时数字（更直观）

---

## 禁止事项

- ❌ 不使用纯白背景 + 黑色文字（太普通）
- ❌ 不使用超过5种颜色
- ❌ 不在同一张幻灯片放超过3个图表
- ❌ 不使用技术术语首字母缩写（LLM/RAG/MCP等需要有解释）
- ❌ 不使用AI幻觉数据（所有数据必须有来源）

## 5. 三指标体系页（KPI框架页）

**用途：** 展示收入/风险/效率三大维度价值体系

**布局：**
```
页面标题：指标体系：基于[X]、[Y]、[Z]三大要素，构筑[行业]AI价值体系

主内容区（左70%）：
┌──────────────────────────────────────────────┐
│ 1. 促收入 = AI触客率 × 产品收益 × 产品转化率  │  ← 红色编号+公式
│    ▶ 智能营销类：[一句话说明]                  │  ← 浅灰子区域
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ 2. 控风险 = AI召回率 × 反欺诈/风险敞口 × 准确率│
│    ▶ 风控以及反欺诈类：[一句话说明]            │
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐
│ 3. 提效率 = AI数字劳动力 × 自动化比例 × 复杂度 │
│    ▶ 智能审核类：[一句话说明]                  │
└──────────────────────────────────────────────┘

右侧（30%）：价值倍增清单（垂直列表+红色箭头）
  用户规模增长
  活跃度提升
  产品丰富度
  风险损失降低
  合规成本降低
  人力成本递减
```

**PPT生成代码要点：**
- 三个大框用浅灰底色 `#F4F4F4`，各占约 23% 页面高度
- 公式中的变量用红色加粗（`#C00000`）
- 右侧价值倍增用竖向排列+向上红色箭头（↑）

## 6. 底部大模型能力+平台能力双框

**用途：** 展示能力演进路径（常出现在页面下半部分）

**布局：**
```
[左框50%：大模型能力 — 改变业务体验/开发范式]  [右框50%：平台能力 — 使能规模化]
  语言生成 → 数据分析整合 → 深度推理           API调用 → 低时延推理 → Agent编排
  图像识别   个性化建模     多模态理解           高可靠   数据安全     强化学习
  内容分析   上下文记忆     自主学习             数据工程  长序列支持    ......
  （用→箭头连接三个发展阶段，体现演进路径）
```
