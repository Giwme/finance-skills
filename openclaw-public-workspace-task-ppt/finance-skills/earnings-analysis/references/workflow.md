# Workflow

## Phase 1 — Data Collection
1. Check current date and record it in working notes.
2. Search latest earnings release, investor presentation, 10-Q/10-K, transcript, and consensus estimates.
3. Verify release date is within the last 3 months unless the user explicitly asks for an older quarter.
4. Confirm transcript date matches release/call date.
5. Download or cite all primary materials with URLs and dates.

## Phase 2 — Analysis
- Quantify beat/miss vs consensus and prior guidance.
- Decompose growth by segment, geography, product, price/volume, and FX where applicable.
- Analyze gross margin, operating margin, EPS, cash flow, working capital, and balance sheet changes.
- Identify management commentary that changes the thesis.
- Update forward estimates and explain each major revision.

## Phase 3 — Charts
Prepare 8-12 charts, prioritizing quarterly progression and new information. Every chart must include source and date.

## Phase 4 — Report
Draft concise institutional-style pages focused on what changed post-earnings.

## Phase 5 — QC
Check all numbers, dates, citations, source links, chart labels, and investment conclusion consistency.
